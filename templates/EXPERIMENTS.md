# 블록별 작업·실험·검증 기록

## 전체 진행
| 블록 ID | 계획 버전·승인 범위 | 상태 | 실험·검사 ID | 코드 commit | 기록 commit/참조 | 다음 승인 |
|---|---|---|---|---|---|---|

## Bxx — 블록 이름 (블록마다 복사)

### 시작 전
- PLAN 버전·관련 요구사항:
- 실제 사용자 승인 근거·범위:
- 목표와 수행 작업:
- 입력 → 출력·변경 파일:
- 실험 가설·변경 변수·고정 조건:
- 예산·중단 조건:

| 검사 ID | 정상/오류/경계/통합 | 실행 방법·입력 | 예상 결과·판정 기준 |
|---|---|---|---|

### 실행 후
- 실제 변경과 계획 대비 차이:
- 재실행 명령·seed·환경:
- 실행 당시 코드 commit·dirty 상태:
- run ID·로그/결과 경로:
- 소요 시간:

| 검사/실험 ID | 실제 명령 | 실제 결과·metric | 통과/실패/미실행/차단 | 근거·한계 |
|---|---|---|---|---|

### 판단과 인계
- AI 제안:
- 사용자가 직접 확인·수정·유지한 내용과 이유:
- 실패 원인·수정·재검증:
- 남은 corner case·미검증 사항:
- 다음 단계 제안:
- 다음 블록 승인 상태:
- Git 변경 파일·커밋 메시지:
- 완료 commit 참조(생성 후 보고·인계, 필요하면 다음 기록에서 hash 추가):

커밋은 자기 hash를 본문에 포함할 수 없다. 실행 코드 버전과 완료 기록 버전을 구분한다. 미실행·추정치를 측정 결과로 기록하지 않는다.
