# 제한 시간 문제 풀이

1. 문제 원문, 기존 저장소, 실행 환경, 허용 도구와 반입 규정을 확인한다. 규칙 미확인은 미확인으로 기록한다.
2. templates/PLAN.md를 참고해 PLAN.md를 채운다. 고정·변경 가능 조건, metric, 입력·출력, 제출물, 성공 조건, 남은 시간을 명시한다. 원본 양식은 보존한다.
3. 구조 변경과 하네스 조정은 시간 예산의 10% 안에서 최소화한다. 실행 가능한 baseline과 평가기를 우선 만든다.
4. metric과 검증 데이터 구성의 타당성을 검토한다. 정답이 없는 테스트 결과를 정확도 검증으로 표현하지 않는다.
5. 실험은 scripts/run_experiment.py로 실행하거나 기존 실행 도구를 사용한다. 상대 경로는 현재 디렉터리 기준임을 확인한다. 로그에 비밀이나 민감한 원문이 출력되지 않도록 한다.
6. templates/EXPERIMENTS.md를 참고해 EXPERIMENTS.md에 가설·변경·시간·실제 결과·실패를 기록한다. 한 번에 가능한 적은 변수를 바꾼다.
7. 남은 시간에 따라 우선순위를 갱신한다. 마지막 20%에는 새 구조 도입을 중단하고 전체 실행과 제출 검증을 수행한다.
8. templates/SUBMISSION.md를 참고해 SUBMISSION.md를 채운다. 문제별 형식 검사는 실제 명세에 맞춰 구현한다. 이 키트는 문제별 검사를 제공하지 않는다.
9. templates/HANDOFF.md를 참고해 HANDOFF.md를 갱신한다. 사용자가 선택한 판단과 AI의 제안을 구분하고 기록을 꾸미지 않는다.
10. 핵심 흐름, 실제 검사, 선택 이유, 남은 위험을 간결하게 보고한다. 보고서는 실행 결과만 근거로 작성한다.
